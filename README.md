# 🍒 ✈️ TRIPCONTROL

### Meu principal projeto em desenvolvimento

</div>

O **TripControl** é meu projeto de conclusão de curso em **Engenharia de Software** e representa uma etapa importante da minha transição para o desenvolvimento de software.

A proposta é desenvolver uma aplicação para **planejamento, organização e controle de despesas de viagens**, reunindo informações importantes da viagem em um único ambiente.

Mais do que um projeto acadêmico, ele está sendo construído para demonstrar, na prática, minha evolução em **desenvolvimento Android, programação, banco de dados, arquitetura de software e versionamento**.
